# Sistema de Biblioteca

Sistema simples de gerenciamento de biblioteca desenvolvido em Node.js para funcionamento no terminal.

O projeto permite listar livros, realizar empréstimos, devoluções e buscas por título utilizando um menu interativo no console.

# Funcionalidades

* Listagem de livros disponíveis
* Empréstimo de livros
* Devolução de livros
* Busca de livros por título
* Validação de entradas do usuário
* Mensagens de erro no terminal

# Tecnologias Utilizadas

* Node.js
* JavaScript
* Terminal/Console

---

# Como Executar o Projeto

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/Biblioteca-NodeJS.git
```

Acesse a pasta:

```bash
cd Biblioteca-NodeJS
```

Execute o sistema:

```bash
node index.js
```
